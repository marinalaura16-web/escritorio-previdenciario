# Quebra de Indeferimento

## Protocolo
1. Leia a carta de indeferimento e o processo administrativo.
2. Identifique o motivo formal (transcreva literalmente).
3. Cruze com o processo administrativo.
4. Diagnostique o motivo real: erro de análise, erro de cálculo, regra revogada, falta de documento, indeferimento automático.
5. Recomende: CRPS / Judicial / Complementação.

## Regras
- Se o motivo real não for claro, marque como "indeterminado" e sugira diligência.
- NUNCA afirme erro do INSS sem citar documento específico.
